How to Go Live (5 minutes)

  1. Go to analytics.google.com → create a new property (name: IVCS Website).
  2. Copy the Measurement ID (starts with G-).
  3. Send it to me (or paste it here) and I'll drop it into both pages. No code skills needed on your end.
  4. Optional: link the GA4 property to your Google Ads account so ad clicks show up as sessions and form fills become conversions you can optimize against.
  5. Optional: connect the business phone number to a call-tracking line for exact call attribution per ad.
